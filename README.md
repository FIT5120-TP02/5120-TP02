# 5120-TP02 — SenseWay

Sensory-friendly urban route planning for Melbourne CBD.

## Structure

- `backend/` — FastAPI backend, REST API
- `ds1-ingestion/` — Data ingestion pipeline
- `ds2-baseline/` — Historical baseline computation
- `ds3-sensory-scoring/` — Sensory scoring logic
- `frontend/` — React frontend (Vite)

## Frontend setup

See `frontend/README.md` (or run `cd frontend && npm install && npm run dev`).
